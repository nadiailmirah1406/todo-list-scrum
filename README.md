
# To-Do List Kelompok

## Deskripsi Proyek
To-Do List Kelompok merupakan aplikasi web sederhana yang dibuat untuk membantu pengguna mencatat, mengelola, dan memantau daftar tugas. Aplikasi ini dikembangkan menggunakan HTML, CSS, dan JavaScript tanpa framework tambahan.

## Fitur Aplikasi
1. **Menambahkan Tugas** – Pengguna dapat menambahkan tugas melalui kolom input.
2. **Menandai Tugas Selesai** – Pengguna dapat mengklik tugas untuk menandainya sebagai selesai.
3. **Menghapus Tugas** – Pengguna dapat menghapus tugas dengan mengklik dua kali pada tugas tersebut.
4. **Menghitung Jumlah Tugas** – Aplikasi menampilkan jumlah tugas dan memperbarui angka secara otomatis ketika tugas ditambahkan atau dihapus.

## Teknologi yang Digunakan
- HTML: Membuat struktur halaman web.
- CSS: Mengatur tampilan aplikasi.
- JavaScript: Mengatur fungsi dan interaksi aplikasi.

## Struktur File
- `index.html` – Halaman utama aplikasi.
- `style.css` – Mengatur tampilan aplikasi.
- `script.js` – Menambahkan tugas dan menandai tugas selesai.
- `hapus.js` – Menghapus tugas.
- `hitung.js` – Menghitung jumlah tugas.
- `README.md` – Dokumentasi proyek.

## Cara Menjalankan Aplikasi
1. Unduh atau clone repository ini.
2. Buka folder proyek `todo-list-scrum`.
3. Buka file `index.html` menggunakan browser.
4. Aplikasi To-Do List siap digunakan.

## Pembagian Peran Scrum
Proyek ini dikerjakan secara individu dengan simulasi pembagian peran Scrum sebagai berikut:

- **Product Owner:** Menentukan kebutuhan dan fitur aplikasi berdasarkan User Story.
- **Scrum Master:** Mengatur tahapan Sprint dan memastikan proses pengerjaan berjalan sesuai rencana.
- **Developer:** Membuat halaman, mengembangkan fitur, mengatur tampilan, dan menyusun dokumentasi aplikasi.

## Pengelolaan Proyek
Pengembangan proyek menggunakan Git dan GitHub dengan pendekatan Scrum. Setiap User Story dikerjakan pada branch terpisah, kemudian diajukan melalui Pull Request, diperiksa, dan digabungkan ke branch `main`.
